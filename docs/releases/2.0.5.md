This update makes Stage-Facing screen setup explicit and replaces the unresponsive Live Output popup with an in-app picker.

- Choosing a physical monitor now enables that output. Stage-Facing no longer remains silently Off after a monitor is assigned.
- Enabled is visible beside each screen assignment instead of buried under More options. Disabled outputs are labeled Off.
- Load explains when a loaded Stage-Facing presentation is turned off, or when One screen mode excludes the saved stage output.
- The Live Output picker opens inside SyncShow. Choose Russian, English, or Stage-Facing among the running outputs without changing the cue or the venue setup. Escape closes just the picker.
- Windows and all CI platforms rehearse real mouse clicks, captured previews, stage monitor assignment, and unchanged live cues.

On the church computer: open **Admin Settings → Screen Setup**, assign the Stage-Facing monitor, keep it **Enabled**, and save. Use **Saved screen setup** rather than **One screen** to run audience and stage monitors together. Reopen the intended service and start Show. If a Stage-Facing monitor is not connected, SyncShow does not invent a physical output or steal the operator screen.

The October 4 and October 11 Community documents were inspected read-only and both contain English, Russian, and Media/Stage-Facing channels. Physical church hardware still needs an on-site check after installation.
