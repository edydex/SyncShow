Live translation MVP fixes, validated with a church service on the Windows preview.

- Start and stop live translation from saved Community service cues. SyncShow reads the exact full project behind the loaded service, prepares audio before Start, and checks that the server has the matching saved service.
- Choose a Default audio input in Admin Settings → Translation → Find audio inputs. Translation cues and More controls → Translate use the same saved mixer. The last named input is remembered across restarts, with a fallback for a new venue or Community connection.
- Save OpenAI, source-language, speech, and screen-layout defaults. Text captions are the default; translated speech is optional.
- Translation captions appear in the cue's chosen region. Ordinary slides before and after that region keep their full area. Manual Translate fits the slide above the caption band and continues across ordinary slide navigation until explicitly stopped or Show ends.
- Returning from translation controls to Show keeps the same audio session. Opening Admin Settings during Show no longer leaves the app blocked by an invisible dialog.
- Show distinguishes starting translation from actually receiving captions.

### Using translation

Use a Community with live translation configured by its administrator, including the shared manual/cue control support from [Multilinguum PR #7](https://github.com/edydex/multilinguum/pull/7). Provider credentials stay on that server. An approved SyncShow connection must allow translation control.

Select the mixer once, add Start Translate and Stop Translate cues to the Community plan, save it, and load that saved service in SyncShow. Advance through the preceding slide to prepare audio, then onto Start Translate. Use More controls → Translate for an explicit manual session.

### Release scope and validation

Windows x64, macOS Apple silicon, macOS Intel, and Linux x64 packages are built from the same release source. Package checks cover native image/PDF dependencies, shared service preparation, app launch, Windows installation, artifact integrity, and corresponding dependency sources. The Windows preview was also tested with church audio and presentation screens; this does not claim physical venue testing on Mac or Linux.

This release retains the SyncShow name and existing settings locations. Verse-number spacing and consistent per-song font sizing are reserved for the 2.1.2 preview. The libre.show move is reserved for 2.2.
