SyncShow 2 brings the shared Heritage Community planner into the desktop app and makes last-minute service changes local and quick.

- **Prepare, Load, Show:** one shared planner, offline editing, saved drafts and history, and automatic checks for the latest selected service before presenting. An unavailable server leaves the verified local copy usable with a visible warning.
- **Adjust during Show:** opens the active offline service at the current slide. Edit backstage, see saved changes in thumbnails, then click a slide after closing Adjust to take it live. Edits keep the audience's current screen stable.
- **Reliable navigation:** queued Start Show and Test Output actions, current-slide scrolling across Adjust transitions, stable slide identities after insertions, and warnings only for services dated before the current day.
- **Bilingual presentation:** English and Russian audience choices, per-section primary language, and a simpler single-screen language chooser.
- **Faster preparation:** exact revision reuse and fingerprinted reusable-media caching reduce downloads and repeated package work.
- **Live translation:** continuous captions with rolling history, output previews that follow caption changes, and an optional selected computer-audio source on macOS.

Mac rehearsals cover offline editing, English/Russian/Media outputs, slide insertion, saved preview refresh, and repeated Adjust transitions. Windows and Linux installers also run their native packaged-app checks in CI. Please rehearse screen routing and the church's actual projector on the venue computer before the service.
