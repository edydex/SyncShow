Use 2.0.1 for the live-service rehearsal. It builds on the unified Prepare/Load/Show release and fixes issues found during a deeper offline, bilingual and mid-service editing audit.

- Song lyric corrections, moves and deletions preserve the active slide's identity, primary language, formatting and unedited repeated sections. Duplicates remain independent slides.
- Adjust reopens on an editable audience output after viewing the Stage-Facing Screen and follows the current slide even if a take finishes while it opens.
- Collapsed sections wait for the editor's actual expansion before scrolling to the live slide.
- Cached Add-slide libraries refresh while online and stay available offline with bounded network waits.
- Offline planner drafts, history and cached media use stronger disk-write barriers, including Windows.
- Native Community services keep their own ready status; background Legacy PPTX/Drive scans run only in that mode.
- The packaged editor is checked against its source and shared-core fingerprints. The stable release no longer shows the old Preview badge.

Edits remain backstage until you close Adjust and select a slide. Independently edited repetitions and structurally moved song pages may require a newer Community server to sync their occurrence identities; older servers leave those edits safely saved locally with sync pending. This release does not update the Community server.

See [the release audit](https://github.com/edydex/SyncShow/blob/v2.0.1/docs/releases/2.0.1-audit.md) for fixes, verification and practical limits. Mac packages are ad-hoc signed without notarization; Windows installers are not Authenticode signed.
