# Translation cues (Preview 33)

Prepare Start/Stop Translate cues on individual slides in Heritage Community. Load that exact saved service, then open Translation controls once to select a named mixer, USB, line-in or virtual audio input. Input choice is scoped to the venue and Community connection; the system-default alias is never used for automatic capture.

In Show, the slide before Start prepares the local input and processor but sends no PCM. The marked slide begins translation; Stop ends this controller’s session. Skipping, going backward, ending Show, and closing the app reconcile the intended state rather than queuing obsolete start requests. Other operators’ sessions are never stopped. A missing source, stale service plan or unavailable processor produces a visible status with a link to Translation controls.

Ticker, full-screen, lower-third and hidden display choices remain in output translation settings. Optional translated audio for listeners follows the service plan. Normal slides remain available offline; live translation requires the church server/network. Physical mixer routing is a venue acceptance check.
