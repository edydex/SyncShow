# Planned translation cues

Prepare Start/Stop Translate cues in Heritage Community. Start opens a settings dialog for language, optional listener voice, screen language and ticker or sentence captions. Existing cues offer Edit Translation Settings. Save the service and load its exact revision in SyncShow.

Caption bands reserve 12% (ticker) or 29% (sentences) of the slide height, across the full width. Content wraps within the remaining area and text reduces only when necessary; the whole slide is not scaled down. Plan images and objects inside that area. Thumbnails and live native scenes share the reservation. Stage-facing screens keep their full area. Renderer version 18 marks this layout behavior; version 17 packages remain readable with their original renderer behavior.

Before Show, open Translation setup and choose a named mixer, USB, line-in, virtual audio device, or Computer audio. Computer audio captures sound from all apps, such as a sermon playing in Safari. Close or mute unrelated apps. The temporary video track required by browser capture is stopped immediately and never sent; only audio enters the processor. Grant macOS recording permission and restart the app if prompted. Connect the input to check its level before starting. Input choice is scoped to the venue and Community connection; automatic capture never falls back to the system-default microphone.

In Show, the slide before Start prepares the local input and processor without sending audio. The marked slide begins translation; Stop ends this controller's session. Skipping, going backward, ending Show, and closing the app reconcile the intended state rather than queuing obsolete requests. Other operators' sessions are never stopped. A missing source, stale service plan or unavailable processor produces a visible status with a link to setup.

Optional translated audio for listeners follows the planned setting. Prepared slides remain available offline; live translation requires the church server and network. Physical mixer routing remains a venue acceptance check.
