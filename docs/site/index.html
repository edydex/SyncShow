One calm workflow

Prepare. Load. Show.

Technical venue setup stays behind Admin Settings. The regular operator sees the files that matter, their readiness, and the next safe action.

01

Prepare consistently

Build a service from songs, Bible passages, text, pictures, and existing PowerPoint files with reusable presentation presets.

02

Load with fewer mistakes

Choose files manually or connect one approved folder. SyncShow matches a coherent service date and keeps a verified offline copy.

03

Run every output together

Advance configurable language, room, stream, and Singer outputs in sync, with live Bible passages and a trusted-network phone remote.

Optional Google Drive connection

The folder you choose. Nothing broader.

Private Drive access uses Google’s narrow drive.file permission and a Google-controlled folder picker. A public shared-folder link works without signing in and remains view-only.

✓

Local-first processing

Slides are downloaded, converted, and cached on the church computer—not uploaded to a SyncShow server.

✓

No silent changes

Automatic loading reads files only. A Drive file changes only after the operator enables publishing and deliberately chooses a Publish action.

✓

No ads, tracking, or data sale

This site uses no analytics or advertising scripts. SyncShow does not sell Google user data or use presentation content to train AI.
